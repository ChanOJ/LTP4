» Rules for 64k and demo competitions


Note about authorized external libs for the PC demos (64kb mostly,
and, by extension, 'regular' demos)

NB : Questions may be send into forum.

Windows: you can access every dynamic libraries that result
from a standard installation of Windows and DirectX, plus the
required drivers of the video board. This amounts to having,
for instance, kernel32.dll, dsound.dll, opengl32.dll, etc...
These libraries are considered necessary to give access to
the OS and the hardware. Other libraries, not falling into
this category, will not be allowed (for instance: midas.dll,
bass.dll, fsound.dll, openptc.dll etc...). Note: yes, you then have access, throught Win32, to compression API, and even to 'extract.exe' if you're that desparate.

For DOS entries, DOS-extenders DOS4GW.EXE and CWSDPMI.EXE will be supplied externally. Latest VESA2 drivers will be used for video. These standard external libraries and DOS-extenders will not count in the size of the entry.

Read the add-on.

Linux: standard, up-to-date, distribution will be used (most
probably Debian or Mandrake, although we cannot tell now
which one it will actually be. Things can change till August.).
You will anyway have at least access to: 2.2 kernel (->/dev/fb), maybe some XFree4.x X11 server (XFree3.x is anything's wrong with those 4.x), OSS, plus all the standard libraries and utils (including zlib.so, e.g.). libGGI, MesaGL and OpenGL libraries will be available, too. If your demos must be run with a specific X11's display (8bpp/16bpp,etc..), you should specify it when submitting your entry, so we can launch the correct X server. For /dev/fb, we will most probably select a 16bpp VESA mode at boot time. This is not yet decided, and needs further tests.

Read the add-on.

Final word: the idea behind these, maybe incomplete, rules is:
everything that is OS- or Hardware-related will be supplied
externally. This is the price to pay for having a multi-plateform
common compo. Everything that is software/algorithm is your
problem (and your fun). You won't have to worry about the former,
now focus on the later :)

ADDON (06/06/2000)

I apologize for the rules being unclear. Here are some precisions
about the use of external libraries for the PC-Demo-compo
(not the 64k one):

You can provide any external libraries (.dll, .so), not
falling into the previous "hardware/OS-related" category,
with your demo archive. The size will count in the entry's
total size, however.

For instance, this applies to bass.dll, ptc.dll, etc...

If you feel that these libraries are "standard" enough, and don't need being spread within the final archive of your entry, just provide a "final.zip" without them.

Rationale:
- this will avoid versioning problems (if any).
- and above all, the main reason for not having those famous .dll into the c:\windows\system directory is that there is no easy way to check that a 64k is *not* using a .dll installed there. By "no easy way", I mean: "no-easy-way-when-you-re-four-hours-late-and- urged-into-checking-the-entries-faster" ;)
